## A11Y-06 deviation (decided by the user)

A11Y-06 asks for "an automated axe check plus a manual keyboard and screen-reader pass". No axe library is approved: CLAUDE.md forbids new libraries, including test libraries, without asking, and the user has deferred that approval. This plan therefore does **not** add axe-core, jest-axe, Playwright or any other package. The automated half is covered by:

1. **Lighthouse accessibility audits** run by the user in Chrome DevTools (Lighthouse runs axe-core internally) against the local production build in this plan's UAT items, and against the deployed URL in plan 03-05. Pass criterion: no failed accessibility audits and a score of 90 or more on every audited page.
2. **Zero-dependency static gates** in the repository: the `@a11y` served-HTML checks in `scripts/smoke.ts`, the stylesheet test in `lib/a11y/css-checks.test.ts`, and the existing contrast gate `scripts/check-contrast.ts`.

This is a deliberate deviation from the literal "automated axe check": the axe engine still runs (inside Lighthouse) but is triggered by hand, because no browser automation or axe package may be added.

**Contrast:** no new colour pair appears in Phase 3. Episode chips are `text` on `surface-raised`, mini cards `text` on `surface`, hero badges navy on the status fills, the 404 and empty-state copy `text-muted` on `bg` and `surface`, links navy on `blue`; all are already among the 30+ pairs `scripts/check-contrast.ts` checks, so the contrast gate is re-run, not extended.

## Manual-only verification of A11Y-02 and A11Y-04 (user decision, 2026-11-12)

The user decided on 2026-11-12 (after checker warning W4) that the following are verified manually only, in this phase's end-of-phase UAT, and that no automated check is added for them: no new script, test, smoke token, browser automation or package.

- **A11Y-02 beyond the stylesheet test.** The Task 1 stylesheet test proves only that every keyframes block animates transform or opacity and that the reduced-motion blocks turn off the card-morph group and the 404 portal turn. That reduced motion really disables each effect in the browser is checked by named UAT items: 9a tilt, 9b portal spin, 9c star-field drift, 9d pulse and shimmer, 9e card-to-detail morph, 9f flip as a crossfade (plus 9g to 9i for the Phase 3 additions and live toggling).
- **A11Y-04 in full.** 11a touch targets of at least 44 x 44 px, 11b reflow at 320 px, 11c 200% zoom.

Each of these items names its pages, its setup and its pass criterion (see "Human-check items"). An item that is not run stays pending, and A11Y-02 or A11Y-04 is not marked complete until all of its items have passed.
